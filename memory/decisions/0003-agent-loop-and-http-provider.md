# 0003 — Агентный цикл руками, http-провайдер через корпоративный gateway

Дата: 2026-09-11 · Статус: принято · Принял: kiselevame

Уточняет [ADR 0001](0001-stack.md): стек не меняется, меняется одно из оснований его выбора. ADR 0001 не правится — этот документ сужает его.

## Что определяет выбор

К моменту подключения внешней модели в коде сложилось положение, которого ADR 0001 не предполагал:

- **Агентный цикл уже написан руками** — `src/agent/runner.ts`. Провайдер возвращает намерение (`AgentPlan`), инструменты вызывает runner через реестр, ворота `IRREVERSIBLE` закрывают необратимое. Стриминга в интерфейс нет: серверное действие отдаёт готовый `AgentAnswer` одним куском, карточка «что сделал» собирается из шагов после выполнения.
- **Vercel AI SDK не импортируется нигде** (`grep -rn 'from "ai"' src` пуст), хотя лежит в `dependencies`. Это отметило ревью в `docs/review.md` — расхождение кода с ADR.
- **Внешняя модель доступна через корпоративный gateway** в формате OpenAI chat completions: один POST, ключ в заголовке, ответ текстом. Tool-calling не нужен: модель возвращает структурированное намерение, как и предусматривал ADR 0001 для моделей без него.

Основание «агентный цикл со стримингом из коробки» из ADR 0001 перестало быть фактом. Его надо либо реализовать, либо честно снять.

## Что рассматривали

1. **Перевести runner на Vercel AI SDK** (`generateText` / `streamText` с `tools`), чтобы ADR 0001 стал правдой.
   Не проходит по сроку и по риску: цикл работает, покрыт тестами на ворота подтверждения, уступки при недоборе и карточку «что сделал»; переписывать его за день до защиты — менять проверенное на непроверенное. SDK ещё и навязал бы формат провайдера — адаптер под gateway пришлось бы писать всё равно.
2. **Оставить зависимость «на будущее»**, не трогая ADR.
   Не проходит по правилу репозитория: расхождение кода с документом — дефект. Неиспользуемая зависимость в `dependencies` — это ложь в манифесте и лишние килобайты в образе.
3. **Снять основание и удалить зависимость** — принято.

## Что выбрали и почему 🔶

🔶 **Агентный цикл — рукописный, в `runner.ts`. Vercel AI SDK удалён из зависимостей.** Сборка после удаления проходит: импортов не было.

🔶 **Http-провайдер реализован через корпоративный gateway** (`src/agent/http-provider.ts`): формат OpenAI chat completions, модель и адрес из `LLM_MODEL` и `LLM_BASE_URL`, ключ из `LLM_API_KEY` только в заголовке `Authorization`. Системный промпт собирается из реестра инструментов (`allTools()`), ответ модели проходит zod-схему `AgentPlan`. Любая неудача — нет переменных, сеть, таймаут 15 с, не-JSON, объект не по схеме — становится `refuse` с причиной; молчаливого отката на `rules` нет (🔶15 спеки).

🔶 **Основания выбора стека из ADR 0001 сужены до трёх:** один процесс, файловая маршрутизация, один язык с общими типами. Строка «готовый агентный цикл со стримингом» из таблицы свойств больше не является основанием. Остальные аргументы ADR 0001 — Postgres + Drizzle под инварианты, TypeScript на обе стороны, модуль-как-папка — не затронуты.

## Чем платим и что проверить

+ Манифест зависимостей совпадает с кодом; образ легче.
+ Провайдер — один файл, без чужих абстракций: смена gateway или формата ответа — правка в одном месте.
+ Внятный отказ вместо тихого отката: человек на стенде видит, что именно не так с моделью.

− Стриминга ответа в интерфейс нет и не появится без отдельной работы: покупатель ждёт готовый ответ до 15 с.
  _Проверить:_ скелетон в чате виден всё время ожидания; таймаут возвращает отказ, а не зависание.
− Промпт — текст, а не типизированный контракт; расхождение формулировок в промпте и в zod-схеме ловится только тестом.
  _Проверить:_ `src/agent/http-provider.test.ts` — валидный JSON → `pick`, мусор → `refuse`, `{tool: …}` → `refuse`, таймаут → `refuse`, нет ключа → `refuse` до сети. Каждый тест роняется намеренной поломкой кода.
− Gateway может быть недоступен из контейнера стенда.
  _Проверить:_ после деплоя запрос про полутень и глину в режиме `http`; если отказ по сети — `LLM_PROVIDER=rules` на стенде, модель показывается локально. Оба варианта честные: режим виден индикатором на экране.
