# memory/ — что агент читает перед работой и обновляет после

Одна сущность = один файл. Записи не переписываются — добавляются новые со ссылкой на старые.

| Папка | Что | Шаблон |
|---|---|---|
| `decisions/` | архитектурные решения `NNNN-slug.md` | `decisions/0001-stack.md` |
| `mistakes/` | разборы ошибок агента `YYYY-MM-DD-slug.md` — главное поле «Триггер» | `mistakes/_template.md` |
| `services/` | паспорт сервиса — контекст без чтения кода | `services/_template.md` |

Правило: изменение, которое попадёт в коммит, отражается здесь до конца той же сессии.
