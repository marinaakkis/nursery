# Фаза 5 (RELEASE GATE) — артефакты профиля `compact`

> Профиль `docs=compact|full` (дефолт `compact`). Полный профиль — `reference.artifacts.full.md`.

Принцип `compact`: результаты гейтов — компактными таблицами; нарратив-интерпретация опускается. Проверки (security, smoke, DevOps) выполняются в полном объёме в обоих профилях — отличается только форма отчёта.

## Состав артефактов

| Артефакт | Профиль `compact` | Формат | Содержимое |
|---|---|---|---|
| Security report | ✂️ компактный | таблица | findings-таблица (OWASP) + только блокирующие; вердикт PASS/FAIL |
| Smoke report | ✅ всегда | таблица | endpoint · метод · ожид./факт. статус · auth · итог |
| PR description | ✂️ компактная | таблица + краткий список | что изменено · артефакты · результаты проверок · чеклист |
| DevOps-готовность | ✅ гейт | — | Docker/health/env по `rule.devops.*` |
| dev-process-plan | ✅ финализируется | таблицы | — |

## Что опускается/усекается в `compact`

- Нарративная интерпретация security-findings (оставляем таблицу + блокирующие).
- Развёрнутая проза PR-описания «что и зачем» — заменяется кратким списком ключевых изменений.

## Незыблемое

Объём самих проверок (SAST/DAST, smoke по каждому endpoint, DevOps-гейт) не зависит от профиля. smoke-таблица создаётся всегда.
