## Описание колонок

| Колонка | Значение |
|---|---|
| **N** | Порядковый номер |
| **Поле-источник (path)** | Имя/путь поля в системе-источнике (dot+bracket: `a.b[].c`) |
| **Тип источника** | Тип значения; `?` = nullable |
| **Ограничения** | Длина/диапазон/обязательность из источника, напр. `(50)`, `(10)?` |
| **Поле-приёмник (path)** | Имя/путь в системе-приёмнике |
| **Тип приёмника** | Тип значения; `?` = nullable |
| **Формат** | `GUID`/`ISO 8601`/`enum`/`—` |
| **Трансформация** | `прямое` / `формат даты` / `конкатенация` / `константа` / `справочник` / иное |
| **Владелец** | Какая система — источник истины поля |
| **Примечание** | Флаги: `!!! отсутствует в источнике`, значения по умолчанию, ПДн/КТ |

> Первый столбец всегда `N`, последний — `Примечание`. Реальные значения ПДн/КТ не воспроизводить (DLP). Если шлюз/трансформация отсутствуют — артефакт не создаётся (укажи `—` в карточке проекта).
