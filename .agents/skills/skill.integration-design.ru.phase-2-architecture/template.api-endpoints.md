### Ответ

1. **Content-Type:** `<application/json | application/pdf | —>`
2. **Тело ответа:** таблица по `template.data-model` (или `—`).
3. **Статусы:**

| N | Статус | Условие | Тело ответа | Комментарий |
|---|---|---|---|---|
| 1 | `200` | Успешная обработка | `ResourceDto` | |
| 2 | `400` | Ошибка валидации | `ValidationErrorDto` | |
| 3 | `401` | Отсутствует/невалиден токен | `ErrorDto` | |
