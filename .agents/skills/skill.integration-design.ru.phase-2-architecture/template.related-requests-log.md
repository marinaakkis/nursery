## Описание колонок

| Колонка | Значение |
|---|---|
| **N** | Порядковый номер |
| **Тип заявки** | `согласование (Отдел архитектуры / информационной безопасности / инфраструктурного развития)` / `создание УЗ/Service Account` / `выдача доступа` / `инфраструктура` / иное |
| **Система (Service Desk)** | Проект/очередь Service Desk |
| **ID / ссылка** | Номер тикета или ссылка (заполняет пользователь) |
| **Статус** | `Создана` / `На рассмотрении` / `Согласовано` / `Выполнено` / `Отклонено` |
| **Дата** | Дата создания/обновления |
| **Ответственный** | Кто ведёт заявку |

> Заполняется пользователем. Первый столбец всегда `N`. Ссылки на создание заявок — в `skill.integration-design.ru.phase-3-approval/reference.sd-links.md`. В итоговую карточку проекта (`project-card`, раздел «Связанные заявки») этот журнал копируется таблицей.
