## Описание колонок

| Колонка | Значение |
|---|---|
| **N** | Номер свойства; при Стратегии A — иерархическая нумерация вложенности |
| **Свойство модели** | Системное имя (или dot-path при Стратегии Б). Именование: JSON/REST — `camelCase` |
| **Наименование** | Человекочитаемое описание |
| **Тип данных** | `string`/`int`/`decimal`/`bool`/`Guid`/`{}`/`[]Type`/`Type \| Type`; `?` = nullable/optional |
| **Формат** | `GUID`/`ISO 8601`/`email`/`enum`/`maxLength: N`/`[min..max]`/`—` |
| **ПДн?** | Персональные данные: `да`/`нет` |
| **КТ?** | Коммерческая тайна / конфиденциально: `да`/`нет` |
| **Маскирование?** | Требуется ли маскирование при логировании/отображении/передаче: `да`/`нет` |
| **Комментарий** | Бизнес-правила, ограничения, ссылка на enum |

> Первый столбец всегда `N`, последний — `Комментарий`. Колонки `ПДн?/КТ?/Маскирование?` добавлены относительно базового `skill.dev.ru.data-model-table` (требование процесса). Значения ПДн/КТ в документе **не воспроизводятся** (DLP) — фиксируется только факт чувствительности.
