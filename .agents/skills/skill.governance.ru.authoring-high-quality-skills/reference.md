# Шаблон нового скилла (скелет)

Переносимо в любой репозиторий: положи каталог скилла в виде `skill.<domain>.<ru|en>.<skill-name>/` под `.agents/skills/` целевого проекта (см. `rule.governance.ru.cursor-skill-command-rule-filenames.mdc`). Пути к другим скиллам в шаблоне не зашиты.

Скопируй и заполни. Поле `description` пиши **на английском**, третье лицо.

```markdown
---
name: topic-short-name
description: >-
  [WHAT: что делает скилл одним-двумя предложениями].
  [WHEN: Use when … перечисли триггеры и ключевые слова.]
---

# [Название темы]

[1–3 абзаца: скоуп, приоритет над локальными правилами, ссылка на .editorconfig / схему / скрипт, если есть.]

## [Раздел 1 — например соглашения / входные данные]

| Элемент | Правило | Пример |
|--------|---------|--------|
| … | … | `…` |

## [Раздел 2 — процесс / структура]

- …

## [Раздел N — специфика стека]

- …

## Перед сдачей (чеклист)

1. …
2. …

Подробные примеры — [reference.md](reference.md)  <!-- если создаёшь второй файл -->
```

## Мини-чеклист автора скилла

- [ ] `description`: английский, третье лицо, WHAT + WHEN, ≤1024 символов.
- [ ] Разделы покрывают типичные подвопросы темы, не одна свалка.
- [ ] Есть таблица или аналог, если много однотипных правил.
- [ ] Есть чеклист перед сдачей или эквивалент (definition of done).
- [ ] Длинные примеры вынесены; ссылка из `SKILL.md` одноуровневая.
- [ ] Конфликт с конфигом/линтером разрешён явной формулировкой.
