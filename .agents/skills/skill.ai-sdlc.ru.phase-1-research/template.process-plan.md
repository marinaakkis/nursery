## Режимы исполнения и статусы фаз

| Статус | Режим manual/review — итерационный (phase-команды) | Режим auto/plan-review — автоматический (run-all) |
|---|---|---|
| **Не начата** | Фаза не запущена | Фаза не запущена |
| **В работе** | Фаза исполняется агентом | Фаза исполняется агентом |
| **Завершена** | Агент закончил работу; ожидает согласования | Агент закончил работу; автопереход |
| **Согласовано** | Инженер подтвердил результат; **обязателен для перехода к следующей фазе** | **Не используется** — переход по Завершена |

> **Режим manual/review:** следующая phase-команда запускается только после перехода фазы в статус **Согласовано**.
> **Режим auto/plan-review (run-all):** агент переходит к следующей фазе автоматически по статусу **Завершена**; Согласовано не выставляется. В режиме plan-review — после фазы 3 следует пауза для обсуждения открытых вопросов.
