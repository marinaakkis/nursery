### Пример: dev-task

```markdown
# Dev-task: Confluence API клиент и аутентификация

**Системное название:** `api-client-auth`
**Код dev-задачи:** `r-001.t-002`
**Название:** Confluence API клиент и аутентификация
**Версия:** 1.0
**Аннотация:** Реализация HTTP-клиента для Confluence REST API с поддержкой Basic и PAT аутентификации.

---

## Цель

Создать типизированный HTTP-клиент к Confluence API с двумя стратегиями аутентификации (Basic, PAT), retry-логикой и корректной обработкой ошибок.

## Входные условия

- Завершена T-001: инфраструктура проекта и CLI-интерфейс настроены
- Определены интерфейсы клиента в `adr.002.onprem-auth-strategy.md`

## Описание

Создать типизированный HTTP-клиент к Confluence Data Center/Server API.  
Требования: [furps.confluence-extractor.md](../../requirements/furps.confluence-extractor.md).  
Решения по аутентификации: [adr.002.onprem-auth-strategy.md](../../adr-log/adr.002.onprem-auth-strategy.md).

## Шаги реализации

1. Создать интерфейс `IConfluenceClient` с методами `GetPage`, `GetChildren`, `GetAttachments` → Интерфейс без реализации, только контракт
2. Реализовать `BasicAuthStrategy`: заголовок `Authorization: Basic <base64>` → Покрыт юнит-тестами
3. Реализовать `PatAuthStrategy`: заголовок `Authorization: Bearer <token>` → Покрыт юнит-тестами
4. Реализовать `ConfluenceHttpClient`: retry (3 попытки, exponential backoff), таймаут 30 с → Интеграционные тесты через mock-сервер

## Тест-кейсы

| # | Сценарий | Вход | Ожидаемый выход | Уровень |
|---|---|---|---|---|
| 1 | Успешный запрос страницы | Валидный page ID, Basic auth | JSON-структура страницы | Integration |
| 2 | Неверные credentials | Неверный token | HTTP 401, сообщение об ошибке | Unit |
| 3 | Таймаут запроса | Сервер не отвечает 31 с | Исключение с описанием retry-попыток | Unit |

## Acceptance Criteria

- [ ] `BasicAuthStrategy` и `PatAuthStrategy` реализованы и покрыты юнит-тестами
- [ ] Оба варианта выбираемы через CLI-параметр `--auth-type`
- [ ] Ошибки аутентификации логируются структурировано
- [ ] Билд проходит без ошибок
- [ ] Все тесты зелёные
- [ ] Линтеры без ошибок
- [ ] Соответствие дизайну проверено
- [ ] Security-review пройден: credentials не логируются, нет hardcoded secrets
```
