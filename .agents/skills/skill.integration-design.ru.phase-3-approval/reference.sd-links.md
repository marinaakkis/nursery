## Описание колонок

| Колонка | Значение |
|---|---|
| **N** | Порядковый номер |
| **Тип заявки** | Назначение заявки |
| **Отдел** | Кто рассматривает: Отдел архитектуры / Отдел информационной безопасности / Отдел инфраструктурного развития |
| **Ссылка на создание в SD** | URL формы создания (плейсхолдер; заполняет пользователь) |
| **Шаблон заявки** | Какой шаблон использовать для тела |
| **Примечание** | Порядок, условия |

> Это reference-таблица: единая точка, где собраны ссылки на создание заявок, чтобы их не искать. Первый столбец всегда `N`. Не вписывай реальные внутренние URL в общий шаблон (DLP) — только в рабочий экземпляр.
