# Reference: процесс согласования интеграции (расширяемый)

Процесс согласования ведётся **таблицей**, чтобы этапы (отделы) можно было добавлять и убирать. Согласование исполняет **пользователь вручную** в Service Desk; агент готовит заявки и фиксирует статусы.

> Полные названия отделов (используются для устойчивости к сбросу контекста): Отдел архитектуры, Отдел информационной безопасности, Отдел инфраструктурного развития.

## Таблица этапов согласования

| N | Отдел | Условие запуска | Предусловие | Артефакт-заявка | Статус | Дата | Примечание |
|---|---|---|---|---|---|---|---|
| 1 | Отдел архитектуры | Документация фазы 2 готова | карточка проекта + тех-таблица | sd-request | <!-- Создана/На рассмотрении/Согласовано/Отклонено --> | | первым |
| 2 | Отдел информационной безопасности | Запускается параллельно с Отделом архитектуры | модель данных с ПДн/КТ, auth | sd-request | | | обязательна |
| 3 | Отдел инфраструктурного развития | По требованию Отдела архитектуры/информационной безопасности | список требуемых УЗ/доступов/инфры | sd-request | | | по необходимости |

### Правила порядка

1. **Отдел архитектуры — первым.** Заявка на согласование архитектуры интеграции.
2. **Отдел информационной безопасности — параллельно**, не дожидаясь завершения согласования Отделом архитектуры. Заявка обязательна.
3. **Отдел инфраструктурного развития — по требованию** Отдела архитектуры и/или Отдела информационной безопасности (например, нужно создать Service Account, выдать доступы, развернуть инфраструктуру).

### Статусы

`Создана` → `На рассмотрении` → `Согласовано` / `Отклонено`. Пользователь подтверждает статус сам либо просит агента обновить статус в `integration-request-plan`.

## Завершение процесса

Когда все необходимые заявки в статусе `Согласовано` — процесс проектирования и согласования интеграции **завершён**. Зафиксируй итог в `integration-request-plan` (Текущая фаза = DONE). После этого пользователь может инициировать разработку интеграции как отдельный этап.

## Добавление/удаление этапов

Чтобы добавить отдел — добавь строку в таблицу с условием запуска и предусловием. Чтобы убрать — удали строку или пометь «не требуется» в примечании. Первый столбец всегда `N`.
