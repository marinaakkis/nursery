# Промпт проверки платформенности

Проверяет главное свойство продукта: **расширяется ли он по документации, без
устного онбординга.** Запускать в свежей сессии, другим агентом.

Задача выбрана так, чтобы её нельзя было сделать копированием: новый тип напоминания
затрагивает схему, сервис, календарь и интерфейс — но не должен требовать правок
в чужих модулях.

---

## Промпт

```
Тебе нужно добавить в продукт новый тип напоминания по уходу — «укрытие на зиму».

Оно отличается от существующих: делается один раз в сезон, а не по периоду,
и вне сезона не считается просроченным.

ЖЁСТКОЕ ОГРАНИЧЕНИЕ: читай только README.md. Ничего больше открывать нельзя —
ни spec.md, ни AGENTS.md, ни ADR, ни чужой код за пределами того, что README
прямо называет как место для правки.

Если README чего-то не объясняет — не догадывайся и не иди искать в других файлах.
Остановись и запиши вопрос. Список таких вопросов — половина результата.

Сделай, сколько получится, и ответь по форме:

1. Что удалось сделать, опираясь только на README.
2. На каком шаге застрял и почему — какого именно знания не хватило.
3. Какие вопросы пришлось бы задать автору.
4. Сколько файлов пришлось создать и изменить. Уложился ли в границы одного модуля,
   как обещает README, или пришлось лезть в чужие.
5. Оценка по пятибалльной шкале: насколько README достаточен для расширения
   продукта без разговора с автором. Обоснуй оценку тем, что произошло,
   а не общими словами.

Код можно не доводить до рабочего состояния — важнее честно показать, где
документация обрывается.
```

---

## Что считать результатом

| Исход | Что означает |
|---|---|
| Дошёл до конца, вопросов нет | README закрывает расширение |
| Дошёл, но с вопросами по деталям | Норма; вопросы — список правок в README |
| Застрял на схеме или на реестре | README не объясняет главного, это дефект документации |
| Полез в чужие модули | Точка расширения заявлена, но не работает — дефект архитектуры |

Результат вписывается в `JOURNAL.md` как отдельная запись: что спросил проверяющий,
где документация оборвалась, что после этого поправили.
