# Команда: Публикация dev-request в хранилище

Публикует артефакты завершённого dev-request во внешнее хранилище, обновляет метаданные проекта.

> Команда оперирует каталогом dev-request как непрозрачным входом и **не зависит от содержимого** конкретных dev-request. Постоянная документация **не ссылается** на файлы внутри `docs/dev-requests/`.

**Аргументы:** `$ARGUMENTS` — опции запуска (см. ниже).

Делегирует детерминированному скрипту `scripts/publish-dev-requests-docs/publish-dev-requests-docs.mjs`.

---

## Опции

| Опция | Назначение |
|---|---|
| `--request r-<nnn>` | Конкретный dev-request в режиме по умолчанию |
| `--all-docs` | Публикует всё дерево `docs/dev-requests/` as-is |
| `--docs-path <путь>` | Публикует конкретный файл или папку внутри `docs/dev-requests/` |
| `--with-clean` | Удалить исходники после успешной публикации (все режимы) |
| `--dry-run` | Показать план без реальной публикации |
| `--help` | Справка |

Бэкенд и секреты — только из `.project-metadata.local.json` (gitignored) → `docsStorage`.

---

## Конвейер (3 стадии + опц. clean)

1. **init-dev-requests-publishing** — прочитать `.project-metadata.local.json` (создаётся с дефолтами если отсутствует); определить папку запроса `r-<nnn>`.
2. **prepare-dev-requests** — собрать манифест артефактов (по умолчанию только `DONE`).
3. **publish-dev-requests** — пакетная параллельная загрузка в хранилище через адаптер (REST) с timeout/retry/circuit-breaker.
4. **clean-published-dev-requests** — удаляет папку запроса целиком. Выполняется только при флаге `--with-clean`.

> Скрипт **не выполняет** `git add`/commit/push.

---

## Шаги исполнения

1. Прочитать `$ARGUMENTS`; определить целевой `--request` (если не задан и dev-request не единственный — запросить у пользователя явный выбор).
2. **Сначала dry-run:** `node scripts/publish-dev-requests-docs/publish-dev-requests-docs.mjs --request r-<nnn> --dry-run` — показать план.
3. После подтверждения пользователя — выполнить без `--dry-run`.
4. Сообщить итог: число опубликованных артефактов, бэкенд/проект, обновление метаданных.
